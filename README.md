# FaasKids Invoice Generator 🧾

A simple invoice generator for **FaasKids** — *Grow with Style*.

## Features
- Add items from the catalogue (Water Bottle, Backpack, Snackbox, Snackpack, Girls Dress, Boys Dress, Shoes, Inner Wear) or type a custom item
- Quantity stepper and manual price entry, with quick-price buttons (₦22,000 / ₦27,000)
- Optional delivery fee and discount
- Auto invoice numbers (FK-YYMMDD-NNN), date, live preview
- Print / save as PDF (branded layout)
- Send invoice summary straight to the customer on WhatsApp
- Notes / payment details saved on the device

## Running
Static site — no build step. Open `index.html`, or deploy the repo root to Vercel.
